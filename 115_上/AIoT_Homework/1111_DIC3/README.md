# 1111_DIC3

摘要
臺中市政府 2025 年統計顯示，2024 年底臺中市餐飲業達 22,612 家，較 2015 年成長 47.55%，全年銷售額突破 1,156.89 億元，顯示約會、慶生與朋友聚餐等外食需求龐大。然而，現有餐廳推薦系統多僅比對評論與情境語意，未將公車候車、轉乘、步行與抵達時間納入決策，導致語意相符卻難以準時抵達。本研究提出「考量臺中公車交通便利性的情境感知餐廳推薦 AI Agent System」，以 LLM 解析自然語言需求，結合向量與混合檢索比對情境及評論，並以知識圖譜保存餐廳、評論、站牌與路線等結構化證據；同時介接 TDX 即時公車資料，透過通過（T）、不通過（F）、不確定（U）三值查核預算、營業時間與搭乘條件，建立抵達及用餐時間線。研究將評估混合檢索品質、交通條件對推薦的影響、三值查核防範過度承諾之成效，以及完整時間線對錯過班車與用餐超時的防護，預期提供兼具情境契合、交通可行與可解釋依據的餐廳推薦。
