# 1111_DIC3

摘要
臺中市政府 2025 年統計顯示，2024 年底臺中市餐飲業達 22,612 家，較 2015 年成長 47.55%，全年銷售額突破 1,156.89 億元，顯示約會、慶生與朋友聚餐等外食需求龐大。然而，現有餐廳推薦系統多僅比對評論與情境語意，未將公車候車、轉乘、步行與抵達時間納入決策，導致語意相符卻難以準時抵達。本研究提出「考量臺中公車交通便利性的情境感知餐廳推薦 AI Agent System」，以 LLM 解析自然語言需求，結合向量與混合檢索比對情境及評論，並以知識圖譜保存餐廳、評論、站牌與路線等結構化證據；同時介接 TDX 即時公車資料，透過通過（T）、不通過（F）、不確定（U）三值查核預算、營業時間與搭乘條件，建立抵達及用餐時間線。研究將評估混合檢索品質、交通條件對推薦的影響、三值查核防範過度承諾之成效，以及完整時間線對錯過班車與用餐超時的防護，預期提供兼具情境契合、交通可行與可解釋依據的餐廳推薦。

## Taichung Bus-Aware Restaurant AI Agent: Three Core Innovations

本研究提出一套**考量臺中公車交通便利性的情境感知餐廳推薦 AI Agent System**，旨在突破傳統餐廳推薦偏重語意相符或地理距離、卻未充分考慮實際搭乘公車能否順利抵達及完成用餐的限制。

本系統規劃三大核心創新：

### 1. Context-Aware Semantic Grounding — 情境感知語意檢索與證據對齊

透過大型語言模型理解約會、慶生、朋友聚餐等自然語言用餐需求，運用 **BM25、向量檢索與混合檢索**，從開發者挑選的臺中美食影片逐字稿、說明與留言中召回具情境支持的候選餐廳；結合結構化知識與來源片段，保留推薦理由的原始依據，避免僅憑關鍵字或未經查證的生成內容推薦餐廳。

### 2. Transit-Aware Temporal Decision Making — 公車交通感知與時間相依決策

透過 **TDX 公共運輸旅運規劃與公車資料**，將出發位置、步行、候車、乘車、轉乘、抵達與預計用餐時段納入同一條時間線；在**最終餐廳排序之前**分析各候選餐廳的公車搭乘方案，檢查能否趕上班次、順利轉乘並於營業時間內完成用餐，讓交通可行性真正影響餐廳選擇，而非選定餐廳後才附上路線。

### 3. Evidence-Grounded Constraint Verification — 證據驅動的三值查核與可解釋推薦

將大型語言模型的需求理解與**程式化限制查核**分工，依餐費預算、營業區間、步行上限、候車限制及轉乘條件，對「餐廳 × 公車方案」執行**通過（T）／不通過（F）／不確定（U）**三值判定。已知不符者排除，證據不足者列為暫定，僅將必要條件全部通過的方案納入已驗證排序；最終為最多三間不同餐廳提供情境證據、公車方案、交通負擔及判定原因，以降低缺乏依據的推薦承諾。

**核心研究價值：** 從「只看餐廳評論與偏好的語意推薦（Semantic-Only Restaurant Recommendation）」邁向「**情境先召回、交通先查核、證據可追溯的餐廳決策支援（Context-First, Transit-Verified, Evidence-Grounded Restaurant Recommendation）**」，使推薦結果同時考量**適合這次用餐、方便搭公車抵達，以及資訊是否足以支持判定**。

> **研究階段說明：** 以上為 Proposal／系統設計階段提出的核心創新與預期價值，並非已驗證之實驗成效；系統實作與評估仍需後續完成。
